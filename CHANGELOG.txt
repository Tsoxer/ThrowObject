THROW OBJECT
Development changelog
Started 11/21/2026
Current release v0.0.15, 11/24/2026
Author/Director/Tester: Tsoxer
Programmer/Debugger: Codex (OpenAI)

The project dates come from the original Blender and private preview records,
the release packaging commits, and the supplied dates for v0.0.11 and v0.0.12. The Skyrim
target throughout gameplay development is SE/AE Steam 1.6.1170.

11/21/2026 — Original model and ThrowObjectAnims1
------------------------------------------------
- Built an original humanoid mannequin in Blender with procedurally generated
  surfaces, clothing and materials, a skinned armature, articulated fingers,
  and a right-hand attachment socket. Kept the mannequin and its source
  separate from Skyrim's game assets.
- Authored Hold Object and an overhand Throw Object at 30 FPS. Hold uses a
  generic grip and a 60-frame loop. Throw starts from the held pose, winds up,
  releases at frame 15, follows through and settles at frame 28. The left hand
  stays free. Props are interchangeable.
- Exported the actual Blender actions and skinned model to GLB. Built the
  Three.js viewer with orbit, zoom, play/pause, looping, speed, frame scrub
  and step, camera presets, prop selection, a release marker and a simulated
  detach from the animated socket. Supplied a local preview and an
  authenticated Anims1 preview.
- Added reproducible Blender generation and PyNifly export scripts with
  sample-count, pose, and event checks. Established the vanilla human
  skeleton and idle as local inputs for the later native HKX export.

11/21/2026 — ThrowObjectAnims2
-----------------------------

  Throw around a single-axis elbow hinge, separate forearm roll, and wrist
  flexion and deviation. Revised the overhand motion and skin at the elbow.
  Kept the hold grip, prop offset, preview controls, and release frame.
- Checked joint lengths, bend angles, arm clearance, and loop continuity at
  all 30 FPS keys and between keys. Reviewed the release and follow-through.

  Carry Sprint for full-speed sprinting. Each loop uses the same right-hand
  grip. The left arm swings freely and the preview floor moves under the
  in-place character. All three gait clips stayed under the Anims2 version.

11/21/2026 — v0.0.1
------------------
- Retargeted the six Anims9 actions against the supplied vanilla skeleton
  and standing idle. Exported x64 HKX using PyNifly, checked packfile
  readback and the 99-bone binding, and packaged the original clips while
  keeping the Bethesda input files private.
- Built the native SKSE64 DLL with CommonLibSSE-NG and Address Library and
  staged the mod for MO2. Added the light ThrowObject.esm, an Open Animation
  Replacer carry condition, and Animation Injector one-shots for Pick Up
  and Throw. Used the six clips without replacing base game animation files.
- Implemented world-object pickup with G, drop with E while carrying, and
  throw with left mouse. The held model is attached visually and the original
  reference is released into Havok. Preserved ownership, stack and reference
  data, and invoked Skyrim's theft alarm for owned items.
- Added item weight, size and type to drag tuning. Added configurable
  force, offsets, keybindings, impact damage, near-miss reactions, and
  assault bounty through the SKSE Menu Framework and INI. Added recovery
  for a save made while an item is parked. The initial runtime report
  identified failed gameplay input, a blank log, and interference with
  third-person vanilla E handling.

11/22/2026 — v0.0.2
------------------
- Replaced numeric scan-code fields with named bindings and interactive
  capture for keyboard and mouse. Added Rebind, Cancel, Clear, Reset to
  Defaults, duplicate detection, immediate application and persistence.
- Added flushed startup and input diagnostics and revised SKSE input
  dispatch. Scoped hold and movement replacement to the active player
  carry state at the maximum signed OAR priority. Used dedicated animation
  events for the pickup and throw one-shots.
- Isolated normal activation from Throw Object's drop binding and stopped
  custom flight handling when Skyrim grabs that reference. The reported
  Dwemer Plate crash occurred after the pickup animation started.

11/22/2026 — v0.0.3

- Replaced that copy path with detached render-only static geometry. Kept

11/22/2026 — v0.0.9
------------------

11/24/2026 — v0.0.13
-------------------
- Nearby non-hostile actors now have a daily tolerance for confirmed
  throws. Adults, children, followers and friendly animals use the same
  per-actor counter. A glancing miss scores no hit. One throw can add at
  most one hit to the same actor.
- Each actor rolls between 3 and 7 by default. The 6 AM game-day boundary
  clears the count and rolls lazily on the next qualifying hit or look
  with the optional meter enabled. Same-day counts and thresholds survive
  travel and loading a matching SKSE co-save. No new script, NPC scan or
  daily timer runs.
- Earlier hits can deal nonlethal, unattributed damage. On reaching the
  threshold, the existing combat, assault bounty and guard handling apply
  according to Skyrim's rules and Throw Object settings. Previously
  hostile actors use the v0.0.12 impact behavior.
- Added Minimum daily tolerance from 1 to 10 and Maximum daily tolerance
  up to 20 in the SKSE Menu Framework. Changed bounds affect future
  rolls. The defaults are 3 and 7, and a 1–20 range is supported.
- Added an optional tolerance meter, off by default. It shows the name
  and confirmed hits over the threshold for the friendly actor at the
  crosshair, such as Nazeem TM: 0/7 or Lydia TM: 3/4. The meter can sit in
  any of the four screen corners. Looking at an actor never adds a hit.
- Copied v0.0.12 and preserved its master, forms, animations and settings
  behavior. Added a separate SKSE co-save record for tolerance. The
  existing held-item record stays compatible.

11/24/2026 — v0.0.14
